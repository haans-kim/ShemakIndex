# Shemak 기능도 — 미구축 화면 확인 요청

작성일: 2026-05-29

## 배경

Shemak 기능도(인덱스)의 모든 불릿 → 산출물 화면 연결을 전수 점검했습니다.
연결(라우팅)은 대부분 정상이나, **불릿을 클릭해도 도달할 화면 본체가 만들어져 있지 않은** 셀이 확인되어 공유합니다.
아래 화면번호는 매핑표(`Control-Tower_불릿_페이지_매핑.xlsx`)·DASH_CODE에는 등록되어 있으나, 실제 대시보드 HTML에는 해당 화면의 콘텐츠/렌더 로직이 없습니다. (원본 mockup과 대조한 결과 누락이 아니라 애초에 미구축 상태)

## 1. 미구축 확정 화면 (4종) — 클릭 시 빈 화면

| 화면번호 | 화면명 | 모듈 | 인덱스 위치 (행 × 영역) | 해당 불릿 |
|---|---|---|---|---|
| **PAN-007** | Process · 채용 | M0 적정인력예측 | 확보/개발 | 채용 계획·정원 갭 충원 시나리오 |
| **PAN-008** | Data | M0 적정인력예측 | 보상 | 인건비 시뮬 (정원 × 페이밴드) |
| **PAN-009** | Simulation | M0 적정인력예측 | 조직운영 / 조직개발 | 인력 시뮬레이션(시점별·동인별) / 조직 재설계 시 인력 재배치 시뮬 |
| **PAN-019** | 동인 트렌드 | M1 거시인력동인 | 조직개발 | 조직 변화 시 동인 시뮬 |

> 현재 증상: 해당 불릿 클릭 → 대시보드가 백지로 표시됨 (화면 전환 변수·번호는 잡히나 그릴 콘텐츠가 없음).

## 2. 부분 구현 화면 (1종) — 화면은 뜨나 데이터 비어 있음

| 화면번호 | 화면명 | 모듈 | 인덱스 위치 | 해당 불릿 | 비고 |
|---|---|---|---|---|---|
| PAN-006 | Tasks | M0 적정인력예측 | 성과관리 | 인당 생산성 모니터링 | 화면은 정상 표시되나, 특정 인물이 선택되지 않으면 Task 목록이 비어 있음(0건) |

## 확인·결정 요청

각 화면에 대해 아래 중 방향을 정해 주시면 반영하겠습니다.

1. **신규 구축** — 해당 화면(콘텐츠·차트)을 새로 제작
2. **연결만 유지** — 화면 미제작, 클릭 시 해당 모듈 기본 화면으로 진입(빈 화면 방지)
3. **불릿 비활성** — 인덱스에서 해당 불릿을 비활성 처리

(PAN-006 Tasks는 화면이 이미 있으므로, 진입 시 기본 인물 자동 선택 여부만 결정하면 됩니다.)

## 참고 — 화면은 있으나 불릿이 연결되지 않은 화면 (고아 화면)

위와 반대로, 매핑표 인벤토리에는 정의되어 있으나 인덱스 불릿이 가리키지 않는 화면도 있습니다. 연결이 필요한지 별도 검토가 필요합니다.

- M4 직무업무가치: PAN-043(직무 가치 산포 Grade), PAN-044(Grade × BFM 매트릭스)
- 실장·팀장·팀원 Agent: AG-002(실·팀 R&R), AG-004(직무 fit·등급 갭), AG-005~011 등
